# Cursor Start

Cursor Start is a legacy Cursor plan for developers in India who subscribed before [The X Subscription](https://cursor.com/help/the-x-subscription/overview.md). It keeps working as it is. New customers choose a plan on The X Subscription; the comparable tier is Plus. See [Legacy Cursor plans](https://cursor.com/docs/account/pricing/legacy-cursor-plans.md).

## What is Cursor Start?

Cursor Start is an India-specific subscription that gives you access to Cursor's agentic coding features: plan work, research your codebase, and run longer agents in Agent, Plan, and Ask modes. The plan includes access to Cursor models (Grok 4.7, Grok 4.6, Grok 4.5, and Composer 2.5) with a larger monthly usage pool than the free Hobby plan, plus Cloud Agents.

## How much does Cursor Start cost?

Cursor Start costs **₹649 per month**, tax-inclusive. You are billed monthly in INR through Stripe.

## Who is eligible to subscribe to Cursor Start?

Cursor Start is available to developers in India only. When you subscribe, you verify an Indian phone number. If you pay with a non-Indian card (for example, some international cards), Cursor may prompt you to complete Indian phone number verification before the plan activates.

## What AI models are available on Cursor Start?

Cursor Start includes access to Cursor models only:

| Model            | On Cursor Start                         |
| ---------------- | --------------------------------------- |
| **Grok 4.7**     | Yes, fixed medium effort, non-fast mode |
| **Grok 4.6**     | Yes, fixed medium effort, non-fast mode |
| **Grok 4.5**     | Yes, fixed medium effort, non-fast mode |
| **Composer 2.5** | Yes, non-fast mode                      |

Auto mode and third-party models (OpenAI, Anthropic, Google, and others) are not available on Cursor Start.

## Can I change Grok effort levels on Cursor Start?

No. On Cursor Start, Grok 4.7, Grok 4.6, and Grok 4.5 all run at a fixed medium effort level in non-fast mode. You cannot switch between low, medium, and high effort, or turn on Fast mode. Move to Premium or higher on The X Subscription, or to a legacy Pro or higher plan, to choose effort levels and Fast mode.

## What features are included in and excluded from Cursor Start?

| Feature                                        | Cursor Start |
| ---------------------------------------------- | ------------ |
| Agent, Plan, and Ask modes                     | Included     |
| Cloud Agents                                   | Included     |
| Grok 4.7, Grok 4.6, Grok 4.5, and Composer 2.5 | Included     |
| Bugbot                                         | Not included |
| Cursor SDK                                     | Not included |
| Automations                                    | Not included |
| Third-party models                             | Not included |
| On-demand spend                                | Not included |

## How does usage work on Cursor Start?

Cursor Start includes a monthly usage pool for Cursor models. Requests in Cursor draw from the monthly pool.

Usage resets each billing cycle. Unused usage does not roll over.

**Grok models vs Composer 2.5:** Grok 4.7, Grok 4.6, and Grok 4.5 draw from the same monthly pool as Composer 2.5, but consume usage faster. Grok 4.5 consumes usage about **3×** faster than Composer 2.5.

Check your remaining usage on [cursor.com/dashboard](https://cursor.com/dashboard).

## What payment methods are supported for Cursor Start?

Cursor Start supports:

- **UPI** (recommended for reliable subscription renewals)
- **Indian credit and debit cards** (3D Secure authentication is required)

Indian card payments sometimes fail at checkout or on renewal because of bank declines or 3DS challenges. If card payment fails, try UPI or a different card.

Subscriptions use India's card mandate rules. Your bank may ask you to approve a maximum monthly charge when you subscribe.

## Is on-demand spend available on Cursor Start?

No. Cursor Start does not include on-demand spend or usage-based overages.

When you reach your monthly usage limit, AI features pause until your usage resets at the start of your next billing cycle.

## Can I upgrade from Cursor Start to another plan?

Cursor Start is a separate India market plan.

Start can only be purchased while your account is on the free plan, so once you move to any other paid plan, including a legacy Pro, Pro+, Ultra, or Teams plan or a plan on The X Subscription, you can't switch back to Start directly.

To move to a legacy Pro, Pro+, Ultra, or Teams plan, use the standard billing flow at [cursor.com/dashboard/billing](https://cursor.com/dashboard/billing) with pricing in USD. To move to The X Subscription, start at [cursor.com/unify](https://cursor.com/unify).

## How does Cursor Start handle support requests?

Cursor Start support tickets are handled by **Sam**, Cursor's AI support agent. Sam can answer common billing and product questions quickly.
